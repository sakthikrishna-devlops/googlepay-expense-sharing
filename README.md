# googlepay-expense-sharing
my first project in python about the sharing of expenses among friends
Expense Sharing System
Project Description

The Expense Sharing System is a Python-based project that helps multiple users share expenses. It supports equal and custom expense splitting, maintains transaction history, displays shared amounts, and calculates the final balances between users.

Features
Add expenses with descriptions and amounts.
Split expenses equally among multiple users.
Split expenses using custom shares.
Maintain transaction history for each user during the program session.
Display shared expense details.
Calculate and display the final settlement balances.
Technologies Used
Python
NumPy
PrettyTable
How to Use
Open the Jupyter Notebook.
Run the expense input cells.
View the shared expense details.
View the transaction history.
Check the final settlement balances.
Storage

Transaction history is stored in a Python list during program execution. The project does not currently use a permanent database.
